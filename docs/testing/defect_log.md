## Defect Status Definitions

- **Open:** Defect identified and not yet fixed.
- **In Progress:** Developer is working on the fix.
- **Fixed:** A fix has been implemented.
- **Retest Pending:** Fix is waiting for verification.
- **Closed:** Retesting confirms the defect is resolved.
- **Reopened:** The defect still occurs after the attempted fix.

## Defect Tracking Procedure

1. Record each defect with a unique defect ID.
2. Mention the related test case ID.
3. Describe the steps required to reproduce the issue.
4. Record expected and actual results.
5. Assign severity and current status.
6. Attach relevant screenshots, logs, or test output.
7. Record the fix commit when available.
8. Perform retesting after the fix.
9. Update the status based on the retest result.
