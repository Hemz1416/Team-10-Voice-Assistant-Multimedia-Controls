## Retest Procedure

1. Identify a defect that has been fixed.
2. Record its defect ID and related test case ID.
3. Note the commit containing the fix, if available.
4. Execute the original test case again.
5. Compare the actual result with the expected result.
6. Record whether the defect is resolved.
7. Update the defect log accordingly.

## Retest Status Definitions

- **Pending:** Retesting has not started.
- **Passed:** The original issue no longer occurs.
- **Failed:** The issue still occurs.
- **Blocked:** Retesting cannot proceed because of a dependency or environment issue.
